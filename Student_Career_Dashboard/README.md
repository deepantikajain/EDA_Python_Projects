# Student Career Analytics Platform

## Overview

The Student Career Analytics Platform is a data-driven web application built using Streamlit. It helps students analyze academic performance, create a structured professional profile, and explore suitable career paths using analytical logic and visualizations.

The project focuses on applying Python, data analysis, and visualization concepts in a practical and interactive way.

---

## Key Features

### Student Performance Analytics
- Subject-wise marks input and analysis  
- Calculation of total marks, average, and grade  
- Data analysis using Pandas  
- Visualizations using Matplotlib and Seaborn  
- Insights such as highest and lowest scoring subjects and variability in marks  

### Resume Builder
- LinkedIn-style profile layout  
- Generic sample data for safe public use  
- Skill evaluation and analysis  
- Visualization of skill levels using charts  
- Structured professional profile preview  

### Career Recommendation System
- Skill-based career matching logic  
- Calculation of career suitability scores  
- Visualization of career match results  
- Identification of the most suitable career path
