# Electronics Sales Analytics Dashboard

An interactive data analytics dashboard built using Python and Streamlit to analyze and visualize electronics sales data.  
This project demonstrates KPI tracking, exploratory data analysis (EDA), and business-focused insights using a realistic CSV dataset.

## Project Overview

The Electronics Sales Analytics Dashboard enables users to analyze sales performance across different regions, products, and time periods. The dashboard provides dynamic filtering, key performance indicators, and visual insights to support data-driven decision making.

---

## Key Features

- Interactive KPI cards for revenue and sales metrics  
- Region-wise and product-wise filtering  
- Revenue analysis by product  
- Units sold trend over time  
- Exploratory Data Analysis (EDA)  
- Correlation heatmap between revenue and units sold  
- CSV-based data loading  
- Clean and professional dark-themed user interface  

---

## Dataset Description

The dataset represents electronics store sales data and is loaded from a CSV file.

Columns used in the dataset:

- Date: Date of the sales transaction  
- Region: Sales region (North, South, East, West)  
- Product: Electronics category (Smartphone, Laptop, Tablet, etc.)  
- Revenue: Revenue generated in INR  
- Units_Sold: Number of units sold

## Insights Generated

- Smartphones show consistent sales across regions  
- Laptops generate high revenue with comparatively lower unit sales  
- Headphones sell in high volume but contribute lower revenue  
- Revenue and units sold show a positive correlation
